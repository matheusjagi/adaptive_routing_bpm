# Adaptive Routing as Operational Insurance

Code and experiments for the paper *"Adaptive Routing as Operational Insurance: A
Training-Free Mechanism for Business-Process Decisions under Changing Costs."*

The repository implements a **cost-tracking, distance-vector routing policy** for a
business-process gateway. Each routable branch keeps a small table of estimated
cost-to-completion, updated as cases resolve (with the announcement lag of case
completion) and, optionally, from still-open cases (a censoring-aware *triggered update*).
The gateway then selects the cheapest branch, subject to a *hold-down* margin. No model is
trained and no process is re-mined; everything used at decision time was observable at
decision time.

## What is evaluated

- **Stage 1 — naturalistic.** The policy is replayed on the real-life **BPIC2017** loan
  application log at the `A_Validating` gateway, under a causally sound protocol
  (announcement lag respected, end-of-log censoring corrected, hyperparameters frozen on a
  temporal split). Produces the main results table and the monthly-regret figure.
- **Stage 2 — artificial.** A semi-synthetic environment with a *known true optimum*
  sweeps the drift rate to characterise *when* adaptivity pays off. Produces the
  drift-pattern table and the phase diagram.

Here, *drift* means the change over time of each branch's completion cost caused by
evolving operational conditions (queues congesting and clearing), not *concept drift* in
the process-mining sense: the control-flow is fixed, only the costs move.

## Repository layout

```
src/                          core library
  config.py                   paths and every experiment constant (map 1:1 to the paper)
  load_log.py                 load / cache the BPIC2017 log
  decision_dataset.py         build the A_Validating decision dataset; censoring
  cost_table.py               sliding-window cost table T_t(b)
  triggered_updates.py        censoring-aware estimate from still-open cases
  policies.py                 static / centralized-retrained / distance-vector policies
  online_policies.py          streaming policy runner (window W, margin m, triggered updates)
  evaluation.py               counterfactual oracle + scoring (regret, optimal rate)
  synthetic_drift.py          drift environment mu_b(t) for Stage 2
prepare_data.py               build the processed data from the raw log
run_final_analysis.py         Stage 1: tune -> freeze -> test, with paired statistical tests
run_synthetic_experiment.py   Stage 2: drift-pattern table + phase-diagram sweep
run_policies.py               quick single-run comparison of the policies
exploration/                  analysis probes and figure scripts
documentation.md              extended technical notes (in Portuguese)
```

python -m venv venv && source venv/bin/activate

## Data

The experiments use the **BPI Challenge 2017** event log (van Dongen, 2017), a public
dataset:

> https://doi.org/10.4121/uuid:5f3067df-f10b-45da-b98b-86ae4c7a310b

Download `BPI_Challenge_2017.xes.gz` and place it in `data/raw/`. The raw log and the
derived files under `data/processed/` are **not** tracked by git (see `.gitignore`); they
are regenerated by `prepare_data.py`.

## Reproducing the results

```bash
# 1. Build the processed log + decision dataset from the raw log
python prepare_data.py

# 2. Stage 1 (real data): tune -> freeze -> test, with paired statistical tests
python run_final_analysis.py

# 3. Stage 2 (semi-synthetic): drift-pattern table + phase-diagram sweep
python run_synthetic_experiment.py

# 4. Figures
python exploration/plot_monthly_regret.py     # monthly regret (Stage 1)
python exploration/plot_synthetic.py          # phase diagram (Stage 2)
```

All experiment constants live in `src/config.py` and match the paper: 60-day warm-up,
30-day retraining cadence, +/-14-day counterfactual oracle window (used for evaluation
only), temporal tune/test split at 2016-07-01, triggered-update parameters
(Delta = 14 days, beta = 1), 41-day end-of-log censoring buffer, and a fixed random seed.
Runs are deterministic given that seed.
